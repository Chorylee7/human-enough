# 人.md

**你接收到了很多信息，但你不欠每一条信息一个回应。**

一份写给容易注意到细节、习惯承担责任、反复解释自己的人的生活手册。

它讨论：没回的消息、别人的情绪、拒绝后的愧疚、停不下来的复盘，以及那些让休息也变成考试的自我要求。

## [开始阅读《人.md》](./人.md)

每章从一个具体场景开始，留下一条可以采取的行动，以及一个可以结束处理的位置。

## 你会读到

- 你看见了，不代表你要负责。
- 没有人给你打分的时候，你也在交卷。
- 你可以让别人失望，而不必成为一个坏人。
- 别人皱了一下眉，你已经修改了整个人生。
- 你不需要证明自己没有恶意。
- 不是所有不舒服，都需要立刻消失。
- 有些问题，想得更久也不会更清楚。
- 你小时候很懂事，长大后可以重新学不会。
- 你已经很累了，不需要再成为一个更好的人。
- 有些环境，确实需要离开。

## 关于这份文档

当前为第一版，欢迎讨论和修订。这里的“高敏感”是生活体验的称呼，不是诊断；不需要先完成一个人格测试才能阅读。

正文区分生活整理与参考依据，不把“早熟的人一般都晚熟”当作心理学定律，也不把现实中的伤害归咎于个人敏感。专业支持的边界与参考资料见正文末尾。

## 如何参与

欢迎通过 Issue 或 Pull Request 提交具体场景、反例、文字修改与有来源的参考材料。请说明建议适用于什么情况；分享经历时请去除个人身份、私人聊天和其他敏感信息。

我们希望每个条目帮助读者少背一个不必要的任务。
