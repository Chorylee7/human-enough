# 封面设计说明

中文标题：不必懂事指南。

中文副标题：你可以体谅别人，也不必总委屈自己。

当前中文封面：`cover-zh.png`。生成方式：OpenAI 内置 imagegen。

概念：接收很多信息，但不需要回应所有信息。以温暖的纸张、透明的人形和细线表现开放与选择，大部分信号经过，少数橙色信号留下。

中文采用暖象牙白、陶土与杏色，标题在左，人形在右。标题分为“不必懂事”和“指南”两行，下方放置副标题，保持清晰易读与充分留白。

英文稿封面暂存为 `cover-en.png`，目前不在首页展示。

配套封面提示词见 [cover-pair-prompts.md](./cover-pair-prompts.md)。
